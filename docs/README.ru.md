# PokéDesk — Pokémon FireRed на Mac с автоматизацией

**[Скачать для Mac с чипом M](https://github.com/redmoongames/pokedesk/releases/download/v0.1.0-beta.1/PokeDesk-0.1.0-beta.1-macos-arm64.dmg)** · [English](../README.md)

Игра в отдельном окне, рядом — команда, прокачка и поиск покемонов по параметрам.
**F9 возвращает управление от бота.** Python, Tk и mGBA уже входят в приложение.
Терминал, Homebrew, CUDA, отдельный эмулятор и аккаунты не нужны.

## Запуск

1. Скачай DMG, открой его и перетащи **PokeDesk.app** в **Applications**.
2. Открой PokéDesk, нажми **Choose ROM…** и выбери собственный `.gba`.
3. После подготовки нажми **Begin** или **File → Continue / Begin**.
   Новые прохождения создаются отдельно через **+ New playthrough**.

Нужны **Mac с чипом M и macOS 13+**. Это первая публичная бета: приложение подписано
локальной ad-hoc подписью, но не нотарифицировано Apple. Если macOS блокирует
запуск, попробуй открыть приложение, затем зайди в **Системные настройки →
Конфиденциальность и безопасность → Всё равно открыть** для PokéDesk, если
доверяешь этому релизу. [Инструкция Apple](https://support.apple.com/en-us/102445).
Отключать защиту через терминал не требуется; на управляемом Mac открытие может
быть запрещено администратором.

## Какой файл игры нужен

**Pokémon FireRed, английская USA/Europe revision 1 (v1.1)**, формат `.gba`,
размер **16 МиБ / 16 777 216 байт**, SHA-1:
`dd5945db9b930750cb39d00c84da8571feebf417`.
Приложение проверит файл автоматически. Переводы, модификации, другие ревизии,
LeafGreen, ZIP-архивы и сохранения `.sav` не подходят.

ROM — цифровой образ картриджа. Его можно считать со своего GBA-картриджа
совместимым считывателем, например с помощью [FlashGBX](https://github.com/lesserkuma/FlashGBX).
**Игры и чужие сохранения не входят в релиз.** Приложение не загружает ROM в сеть;
спрайты и игровые таблицы готовятся локально из выбранного файла, без интернета.

## Управление

- Стрелки или WASD — движение.
- X / E — A, подтверждение; Z / Q — B, назад.
- Enter — Start; правый Shift — Select.
- Пробел — пауза и продолжение.
- **F9 — забрать управление**, Escape — остановить бота и поставить игру на паузу.
- Если F9 управляет мультимедиа, используй **Fn/Globe + F9**.

В настройках можно назначить до двух физических клавиш на кнопку и изменить
скорости на цифрах 0–9. Раскладка клавиатуры не влияет на назначения. Звук по
умолчанию выключен. Язык интерфейса выбирается в Settings; названия покемонов
читаются из английского картриджа, часть справочных текстов ещё локализуется.

## Автоматизация

**Party → Auto Train**: выбери покемона и целевой уровень, проверь маршрут,
команду и решения по приёмам/эволюциям. Статистика учитывает XP за минуту реального
времени и полные циклы между лечениями.

**Pokémon → Auto Catch**: выбери вид, пол, shiny, приоритеты характеристик и время
поиска. При необходимости задай точные IV и число воркеров. При выборе прежнего
кандидата игра может откатиться к его состоянию — перед этим будет предупреждение.

Автоматизация зависит от сюжета и проверенных переходов. Неожиданные ситуации
могут потребовать вмешательства игрока. В сборке поддерживается FireRed Rev 1;
донорские сохранения и шаблоны доставки предметов не распространяются.

## Сохранения

Данные находятся отдельно от приложения:
`~/Library/Application Support/PokeDesk/`.
Открыть их можно через **File → Open saves folder**.

Автосохранение — каждые **5 секунд активной игры по реальному времени**. Обычный
выход ждёт завершения записи. Обновление `.app` не заменяет сохранения. Для
резервной копии и переноса на другой Mac с чипом M копируй **всю папку PokeDesk**
при закрытом приложении: в ней также лежат ROM, история, слоты и версии заданий.
Старые версии пока не очищаются автоматически.

Существующая частная установка проекта остаётся на своём месте: новая сборка
не переносит и не удаляет её прохождения автоматически.
